## 2. 总体架构

单体 Web 应用、前后端分离、REST API(科室内 30~100 人规模,不需要微服务)。

```
┌─ 前端 SPA(Vue3)─────────────────────────────┐
│ 登录 / 人员档案 / 房间 / 月度值班表导入        │
│ 排班工作台(生成→调整→确认) / 周·月总览      │
│ 我的排班 /(二期)请假·请求·肝移植            │
└──────────────────┬───────────────────────────┘
                   │ REST + JWT
┌──────────────────┴───────────────────────────┐
│ Spring Boot 单体                              │
│ ① 基础数据:人员/房间/亚专科/排班参数        │
│ ② 月度值班表导入(Excel 解析校验)           │
│ ③ 排班引擎(规则管道)★系统核心              │
│ ④ 排班快照:生成/手动调整/确认/导出          │
│ ⑤ 二期:外围轮转/肝移植流转/请假/排班请求    │
│ ⑥ 三期:统计报表                             │
└──────────────────┬───────────────────────────┘
                 MySQL 8
```

### 排班引擎设计原则

1. **规则管道**:请假确认(二期)→ 值班组 → 接班/备班 → 手术室分配 → 外围轮转(二期)→ 咨询(二期)→ 肝移植编组(二期)。每一步消费上一步产出的"当日人员占用",保证一人不双岗。
2. **随机可复现**:所有随机环节使用统一随机种子(seed),同数据 + 同 seed 生成结果一致;seed 随排班快照落库,便于回溯与重新生成。
3. **人工调整覆盖层**:引擎产出 `AUTO` 结果;总值班手动修改生成 `MANUAL` 覆盖记录并留痕(改前快照),不回写引擎。
4. **参数数据化**:特殊人员名单、固定房间分配、预留间数等全部存配置表,不写死代码——需求确认后改数据即可,不用改程序。
5. **失败重试**:任一环节排不下时整体重试(默认上限 20 次),仍失败则返回具体的缺人/缺房明细,不静默出错。

## 4. 一期详细设计(排班核心)

### 4.1 范围

**做**:
- 登录与角色:总值班(ADMIN,全部管理操作)/ 普通成员(USER,查看与个人相关操作)
- 人员档案:角色(主任/主麻/预备/本院/规培3-2-1年级/麻护/进修/轮转)、副麻级别、亚专科、带教关系
- 手术室房间档案:房间号、区域(如 8 号楼 4 楼)、星标
- 排班参数:固定分配(陆珠凤→22–29、备班1→802–825)、特殊单间人员名单、预留间数
- 月度值班备班表:Excel 导入 + 模板下载 + 人名校验 + 在线表格编辑
- 排班引擎:值班/备班/接班规则 + 手术室一键排班(随机可复现 + 重试)
- 排班工作台:选日期 → 一键生成 → 按"房间/岗位/人员"三视图 → 手动调整(留痕)→ 确认发布
- 排班总览:人员 × 日期 周/月矩阵,Excel 导出;成员视角"我的排班"

**不做**(数据结构预留扩展点):外围排班、肝移植、请假/假期台账、排班请求、统计报表。

骨架已落地(后端 `mvnw compile`、前端 `type-check + build` 均验证通过)。
完整目录树以 [README.md「目录结构」](../README.md)为唯一维护处,此处只列要点:

- `backend/src/main/resources/db/schema.sql`:一期 10 张核心表建表脚本(含初始排班参数)
- `frontend/src/views/`:login / admin(人员·房间·参数) / roster(月度表) / workbench(排班工作台) / overview(总览·我的)

### 4.3 数据库核心表

| 表 | 关键字段 | 说明 |
|---|---|---|
| `sys_user` | username、password_hash、staff_id、role(ADMIN/USER) | 登录账号,关联人员 |
| `staff` | name、emp_no、job_role(主任/主麻/预备/本院/规培Y3/Y2/Y1/麻护/进修/轮转)、sub_level(1~5,可空)、specialty_id、mentor_id、active | 人员档案;mentor_id 表达带教关系 |
| `specialty` | name | 亚专科 |
| `room` | code、area、starred、sort、active | 手术室房间,星标 |
| `monthly_roster` | year_month、status、created_by | 月度值班备班表(每月一条) |
| `monthly_roster_item` | roster_id、duty_date(可空)、position_type、seq、staff_id | 有 duty_date=当日固定安排(值班、备班1);无 date 有 seq=顺序池(短接班顺延) |
| `schedule` | duty_date、version、seed、status(DRAFT/CONFIRMED)、generated_at、confirmed_at | 每日排班快照,seed 供复现 |
| `schedule_assignment` | schedule_id、staff_id、position_type、room_id、role_tag(主麻/大/小/带教/单间特殊)、source(AUTO/MANUAL)、before_snapshot(JSON) | 排班明细,人工修改留痕 |
| `staff_day_status` | staff_id、date、type(REST_AFTER_CALL/MANUAL_EXCLUDE/MEETING) | 人员×日期状态;一期先落前两类 |
| `schedule_config` | config_key、config_value(JSON) | 固定分配、特殊人员名单、预留间数等,全部数据化 |

### 4.4 排班引擎步骤(一期)

输入:日期 + seed;输出:DRAFT 快照。

```
0. 可用人员池 = 在职 − 当日休息/手动排除(手术室环节另剔除主任)
1. 值班组(月表当日 1老总+1二档+1三档+1四档)最先放入
   → 自动标记次日 REST_AFTER_CALL
2. 备班1(月表当日)→ 固定房间段(读配置)
3. 短接班:从顺序池顺延取人,与备班1同人则跳到下一位;不可用人跳过
4. 长接班;副麻接班(周一~四复制前一日已确认结果,周五重置);副麻中班
5. 手术室分配:
   a. 剔除主任
   b. 固定分配(读配置:陆珠凤→22–29、备班1→802–825)
   c. 按特殊人员名单预留单间(间数读配置)
   d. 主麻随机抽取(seed),有亚专科者优先匹配对应专科房间,直到剩余房间=预留数
   e. 特殊人员进单间
   f. 副麻分配:带教学生优先配自己的主麻 → 剩余房间按"先大后小"随机配
      → 星标房优先配高级别副麻(按假设 A1:5 级最高)
   g. 任一环节排不下 → 整体重试(≤20 次);仍失败返回缺人/缺房明细
6. 落库 DRAFT → 工作台手动调整(逐条留痕)→ 总值班确认 CONFIRM
```

### 4.5 API 概览

| 方法与路径 | 说明 |
|---|---|
| `POST /api/auth/login` | 登录,返回 JWT |
| `/api/staff`、`/api/rooms`、`/api/specialties`、`/api/configs` CRUD | 档案与参数管理(ADMIN) |
| `POST /api/roster/import` + `GET /api/roster/template` | 月度表 Excel 导入 + 模板下载(含人名匹配/冲突校验) |
| `GET /api/roster/{yearMonth}` | 查询/在线编辑月度表 |
| `POST /api/schedule/generate` | 按日期一键生成(可指定 seed 复现) |
| `GET /api/schedule/{date}` | 查看当日快照(含留痕) |
| `PUT /api/schedule/{id}/assignments` | 手动调整(换人/换房,留痕) |
| `POST /api/schedule/{id}/confirm` | 确认发布 |
| `GET /api/schedule/view?range=week\|month` | 周/月矩阵 |
| `GET /api/schedule/{id}/export` | 导出 Excel |

### 4.6 前端页面

1. **登录页**
2. **系统管理**:人员(含带教/级别/亚专科)、房间(星标)、排班参数(特殊人员/固定分配/预留间数)
3. **月度值班表**:上传 → 预览校验 → 保存;在线表格编辑

5. **排班总览**:人员 × 日期周/月矩阵,导出;普通成员"我的排班"

## 6. 验收标准(一期)

1. 导入月度表 → 一键生成某工作日排班,**无一人双岗、无房间超配**冲突
2. 手动改一人,留痕完整(能看到改前/改后/操作人)
3. 确认后周视图与 Excel 导出内容正确
4. 引擎单元测试全部通过;同 seed 重复生成结果一致
5. 普通成员登录只能查看,不能修改
