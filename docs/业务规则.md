## 1. 角色与日常流程

| 角色 | 职责 |
|---|---|
| **总值班(老总)** | 全部管理操作的执行者:每月上传值班备班表、每日确认请假、一键生成次日排班、人工微调、确认肝移植安排 |
| **科室成员** | 查看排班、提交请假申请、提交排班请求、术后确认肝移植 |
| **主任** | 不参与排班(手术室排班第一步即剔除) |

核心日常循环(总值班视角):

```
每月一次:  上传当月"值班备班接班"人员表
每天:      查看并删减明日请假 → 确认 → 一键生成明日排班
           (值班组 → 手术室 → 外围 → 咨询 → 肝移植) → 人工微调 → 发布
肝移植术后: 主麻/副麻确认 → 该组转"已确认",肝移植次数 +1
```

## 3. 值班 / 备班 / 接班规则(每日)

**术语**(访谈确认三):

| 术语 | 含义 |
|---|---|
| 短接班 | 主麻晚班人员,下午 4 点左右上班 |
| 副麻中班 | 副麻晚班人员,下午 4 点左右上班 |
| 长接班 | 晚间接班的一种,不能休息(与短接班的具体差别待确认) |

各岗位按优先级进入排班表:

| 岗位 | 规则 |
|---|---|
| **值班** | 1 老总 + 1 二档 + 1 三档 + 1 四档;不能休息;**最先放入排班表;次日自动休息** |
| **备班1** | 每天轮换一人;尽量不能休息(换班需手动改);固定占 8 号楼 4 楼手术室其中两间;**安排手术时第一个安排**(手术分配最高优先级) |
| **短接班** | 按接班顺序依次排;遇换班/休息手动调整;**当日备班1 与短接班为同一人时,由下一位短接班顶上**(备班1 优先占用) |
| **长接班** | 不能休息;直接进入排班 |
| **副麻接班** | 周一~周四自动沿用前一天的排班数据(旧系统只能自动读取 8 人、其余手动;新系统建议全部自动,见假设 A4);**周五重置** |
| **副麻中班** | 即副麻晚班,见术语表 |
| **备班2** | 不进当日值班备班逻辑、可以休息,按普通人员正常排班 |

## 4. 请假与假期

**流程**:

1. 任何人在任何工作日可提交请假申请;系统按**提交时间先后生成序号**并提示排位
2. 总值班可根据明日排班情况**删减**(驳回)请假人员
3. 一键生成次日排班前,总值班必须先查看明日请假情况并**确认**

**假期台账**:

| 项 | 说明 |
|---|---|
| 积休 | 历史遗留休息(**不是**加班兑换);新总值班产生时 +30 天;其他人员余额**用完即归零** |
| 移植休 | 肝移植相关休息;术后时长**仅作记录、不自动折算天数**,休息需另行申请 |
| 剩余天数 | 还可申请使用的天数 |
| 流转天数 | 已申请、未落实(销假)的天数 |

**不扣假的特殊状态**:

| 状态 | 说明 |
|---|---|
| 会议 / 教学 | 属单位工作,当天不参与排班,**不扣假期**(访谈确认四) |
| 特殊情况 | 手动把人从当天排班中排除的手段——**不是休息、不扣假**,方便总值班在 HIS 中手动调整(访谈确认五) |

## 5. 外围排班(按顺序表轮转,副麻以下随机)

总原则:各外围表格按顺序整理、**按次计算(轮转计数)**;主麻做外围需统计次数。

| 岗位 | 人员配置 | 备注 |
|---|---|---|
| 肠镜南区 | 1主麻 + 本院×3 + 规培3年级×1 + 麻护3年级×1 + 进修×1 + 规培1/2年级×2 | ① |
| 肠镜北区 | 1主麻 + 1大 + 1中 + 1小 | 大=本院/规培3年级;小=规培1/2年级、麻护3年级、进修;"中"未定义(待确认②) |
| 评估门诊 | 1主麻 + 副麻全天×1 + 副麻半天(下午)×1 | 需统计次数 |
| 专家门诊 | 1主麻 | 周一/二/四按指定顺序名单;半天制,可能需老总手动调整 |
| 支气管镜 | 1主麻 + 副麻:5级×1、3级或2级×1、1级×1、麻护×1 | 现为每周二、四 |
| 体检内镜 | 1主麻 + 5级×1(下午半天) + 3级×1 | |

> ① 肠镜南区原文断句有歧义,按"本院 3 人、规培 3 年级 1 人、麻护 3 年级 1 人、进修 1 人、规培 1-2 年级 2 人"理解,请科室核对(假设 A5)。

## 6. 手术室排班算法(一键生成的核心)

**执行顺序**:

1. **剔除主任**
2. 优先安排**陆珠凤** → 房间 22–29
3. 安排**备班1** → 房间 802–825
4. **预留**特殊人员(单间)房间数:张燕影、苏子敏、葛宁花、备班、咨询(视情况 1~2 间)
5. 随机选主麻(每人管两间)排入剩余房间;**有亚专科的主麻优先排到对应专科的房间**;直到剩余房间数 = 预留数
6. 安排特殊人员进单间
7. 副麻分配:**带教学生优先分给自己的带教主麻**;之后剩余房间随机分配副麻
8. 房间或人员排不下时,**整体重新自动排班**(重试)

**术间人员配置**:

- 两间房 = 1 主麻 + 1 大(本院/规培3年级) + 1 小(规培1/2年级、麻护3年级、进修)
- 两间房**先排大、再排小**;带教主麻已占一间带教,另一间给"大";单间人员直接配"小"
- **星标术间**:安排更好的副麻(按副麻级别,访谈确认八)
- **咨询岗**:每周生成,落在对应岗位

**角色与房间管理权限**(访谈确认七):

| 角色 | 房间权限 |
|---|---|
| 主麻 / 总值班 | 管理 2–3 间 |
| 预备 | 管理 1 间(职责同主麻) |
| 规培 / 进修 / 麻护 / 轮转 | 协助主麻管理术间 |

## 7. 肝移植模块

**触发判断**:

- 排班时先判断是否**正常排班**(点"是"):周一排周二、周二排周三、周五排周一 = 正常
- 周六/周日排班 → 自动进入排班日期选择(日期须大于当日);或隔日排班(手动,点"否")= 非正常排班
- 自动提示当前应排人员,可**跳过**

**编组规则**:

- 每天可多组,每组 = **1 主麻 + 1 副麻**,组以序号区分
- 肝移植人员当天**照常参与手术室排班**(肝移植独立于排班系统之外)

**状态机**:

```
未安排(生成后,人员可调整)
  → 总值班调整并确认 → 已安排
  → 术后主麻/副麻确认 → 已确认(肝移植次数 +1)
```

**术后记录**:患者信息、结束时间**手动录入**;仅作记录,不自动换算休息(移植休需另行申请)。

## 8. 排班请求(员工意愿)
